*   Least popular of other browsers mentioned
*   Information is stored in _/Users/$user/Library/Application Support/com.operasoftware.Opera_
    *   Stores browser history and download data in the same format as Chrome
        *   Also applies to the file and table names
        *   _/User/$users/Library/Application Support/com.operasoftware.Opera/History_
*   Timestamps are also stored in microseconds since Jan 1 1601 UTC
